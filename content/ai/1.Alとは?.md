## AIとは？

現在、AI（人工知能）は私たちの暮らしの中でとても身近な存在になっています。スマートフォンの音声アシスタントや、写真に写っているものを自動で見分ける技術、外国語の翻訳など、いろいろな場所で使われています。

このページでは、AIの基本的な考え方や仕組み、ロボットとの違い、これまでの歴史、そしてこれからの未来について、みなさんに分かりやすく解説します。

---

## 1. AI（人工知能）の基本を知ろう！

まずは、AIとは一体何なのか、そしてよく混同されがちな「ロボット」と何が違うのかという基本から見ていきましょう。

### ① AI（人工知能）とは？

AIは英語の「**Artificial Intelligence**（アーティフィシャル・インテリジェンス）」の頭文字を取った言葉で、日本語では「**人工知能**」と呼びます。

簡単に言うと、**「人間のように学んだり、考えたり、判断したりする力をコンピュータで再現したもの」**です。

私たちが普段使っているスマートフォンで「おすすめの動画」が表示されたり、声で操作できたりするのも、このAIの技術が裏側で働いているおかげです。

![[1_02.jpeg]]

### ② AIとロボットの違い

「AI」と「ロボット」は似ているように思えますが、実は役割が全く違います。

* **AI（人工知能）**
  * 人間の「知能」にあたる部分を再現した**ソフトウェア（プログラム）**です。
  * 形はありません。スマートフォンのアプリやインターネット上のシステムの中で動いています。
  * 人間にたとえると**「脳」**の役割をします。
* **ロボット**
  * モーターやセンサーを使い、実際に体を動かす**物理的な機械**です。
  * 目に見える体があります。AIを搭載して賢く動くロボットもあれば、AIは入っておらず決められた通りに動くだけのロボットもあります。
  * 人間にたとえると**「体」**の役割をします。

つまり、**「脳（AI）」が考えた命令に従って、「体（ロボット）」が動く**という関係になります。

| 項目           | AI（人工知能）           | ロボット             |
| :----------- | :----------------- | :--------------- |
| **主な特徴**     | 人間の知能（学ぶ・考える）を再現する | センサーやモーターで物理的に動く |
| **存在の形**     | ソフトウェア（プログラム）      | 物理的な機械（ボディがある）   |
| **人間にたとえると** | **「脳」**            | **「体」**          |
|              |                    |                  |

## 2. AIの研究はどこから始まったの？

AIの歴史は、今から70年以上前の1950年代までさかのぼります。

### ダートマス会議での誕生

「AI（人工知能）」という言葉が世界で初めて使われたのは、**1956年**にアメリカで開かれた「**ダートマス会議**」という研究集会でした。ここでは、当時の有名な科学者たちが集まり、「人間のように賢く動くコンピュータプログラムを作ろう」という目標を掲げました。

### コンピュータの進化と戦争の歴史

AI研究が始まった背景には、第二次世界大戦がありました。戦争中に大量の計算を素早く行うためにコンピュータが作られましたが、当時のコンピュータはあらかじめ決められた計算をするだけでした。
研究者たちは「ただ計算するだけでなく、人間のように自分で考えて判断できる機械を作りたい」と考え、研究に熱中していったのです。

初期のAIは現代のように文章や画像を理解することはできず、迷路を解いたりチェスをしたりするような「計算やルールの処理」が得意なだけでした。そこから何十年もの時間をかけて、ゆっくりと進化してきました。

## 3. AIの進化とこれからの課題

その後、コンピュータの性能が上がり、大量のデータを処理できるようになると、AIは「**機械学習（マシンラーニング）**」や「**深層学習（ディープラーニング）**」という新しい技術によって劇的に進化しました。

これにより、AIは自分で画像を見分けるだけでなく、人間のように自然な文章を書いたり、絵を描いたり、音楽を作ったりできるようになりました。


![[1_05.jpeg]]

### これからの課題

AIはとても便利で未来を明るくしてくれる一方で、いくつかの課題も指摘されています。

1. **仕事の変化**：単純な作業がAIに置き換わることで、人間の仕事が減ってしまうのではないかという心配があります。
2. **プライバシーと倫理**：個人情報が勝手に使われたり、AIが間違った情報（偏見）を学習してしまったりする問題があります。
3. **シンギュラリティ（技術的特異点）**：AIの賢さが人間の知能を超えるタイミングが来るのではないかと言われており、人間とAIがどう共存していくかが問われています。

AIの未来は、ただ技術が進むだけでなく、私たちが社会でどのように使っていくかという「マナーやルール」とも深くつながっています。
