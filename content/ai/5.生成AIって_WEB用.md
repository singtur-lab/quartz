# 生成AIってどんなAI？

生成AIは、質問に答えるだけのAIではありません。
文章を書いたり、画像を作ったり、音楽を作ったり、プログラムのコードを書いたりするように、「新しいものを生み出す」ことができるAIです。

ここで大事なのは、生成AIが突然あらわれた魔法ではない、ということです。
生成AIの背景には、ニューラルネットワーク、ディープラーニング、Transformerなど、長い技術の積み重ねがあります。

この記事では、生成AIがどのようなしくみで動いているのかを、順番に整理していきます。


## 1. 生成AIは「分類するAI」から「作るAI」へ進化した

これまでのAIは、主に「分類」や「判定」が得意でした。

たとえば、次のような使い方です。

- この画像は犬か、猫か
- このメールは普通のメールか、迷惑メールか
- このデータは正常か、異常か

つまり、従来のAIは「与えられたものにラベルをつける」ことが中心でした。

一方、生成AIは、大量のデータを学習し、その特徴をもとに新しいデータを作り出します。

たとえば、たくさんの物語を学習したAIに「探検物語を書いて」と頼むと、学習した表現や構成をもとに、新しい物語を作ります。
画像を学習したAIなら、実際には存在しない「空飛ぶネコの画像」のようなものも生成できます。

| 種類 | 得意なこと | 例 |
| --- | --- | --- |
| 従来型AI | 分類・判定 | 犬か猫かを見分ける、迷惑メールを判定する |
| 生成AI | 新しいデータの生成 | 文章、画像、音楽、コードを作る |

生成AIとは、「知っていることを分類するAI」から、「学んだ知識を使って新しいものを作るAI」へ進化したものだと考えるとわかりやすいです。


## 2. 生成AIの始まりにあるボルツマンマシン

生成AIの歴史をたどると、1980年代後半に登場した「ボルツマンマシン」というモデルに行き着きます。

ボルツマンマシンは、ジェフリー・ヒントンやテリー・セジュノスキーらによって研究された、確率を使って学習するニューラルネットワークの一種です。

それまでのAIは、「0」か「1」かという単純な値で世界を扱うのが基本でした。
しかし、現実のデータはもっと複雑です。
人間の表情、文章の意味、画像の特徴などは、きれいに0と1だけで分けられるものではありません。

そこでボルツマンマシンは、0.15や0.92のような中間の値も扱いながら、複雑なデータの特徴を学習しようとしました。

### 入力層と隠れ層

AIのニューラルネットワークは、人間の脳の神経回路をまねたしくみです。
基本的には、情報を受け取る「入力層」と、情報を処理する「隠れ層（学習層）」があります。

| 層 | 役割 | 人間にたとえると |
| --- | --- | --- |
| 入力層 | データが最初に入ってくる場所 | 目や耳 |
| 隠れ層 | 情報を組み合わせ、パターンを見つける場所 | 頭の中で考える部分 |

ただし、初期のボルツマンマシンには大きな弱点がありました。
入力層と隠れ層の区別があいまいで、ノード同士がランダムにつながっていたため、情報の流れが複雑になりすぎたのです。

その結果、複雑なパターンは学べるものの、計算にとても時間がかかりました。
実用化するには、かなり扱いにくいモデルだったわけです。


## 3. 制約付きボルツマンマシンで学習が進みやすくなった

この問題を解決するために登場したのが「制約付きボルツマンマシン」です。

ポイントは、入力層と隠れ層をきれいに分け、同じ層の中では線を結ばないようにしたことです。
この「制約」によって、情報の流れが整理され、学習スピードが大きく向上しました。

制約付きボルツマンマシンは、次のような場面で使われます。

- データの特徴を学習する
- データを分類する
- 次元削減を行う
- 教師あり学習と教師なし学習の両方に応用する

ここで押さえたいのは、「生成AIは、データの特徴をどう学ぶか」という研究の積み重ねから生まれてきたということです。


## 4. 自己回帰モデルは「過去から次を予測する」

自己回帰モデルとは、過去のデータを手がかりに、次に起こることを予測するしくみです。

たとえば、次のようなものが自己回帰モデルの考え方に近いです。

| 対象 | 予測する内容 |
| --- | --- |
| 天気予報 | 昨日と今日の気温や湿度から、明日の天気を予測する |
| 株価予測 | 過去数日の株価から、翌日の値動きを予測する |
| 売上予測 | 過去の販売データから、来月の売上を予測する |
| 文章予測 | ここまでの単語から、次に来る単語を予測する |

文章生成AIも、基本的には「ここまでの文脈から、次に来る言葉を予測する」という考え方と深く関係しています。

ただし、自己回帰モデルには弱点もあります。
過去の流れをもとに予測するため、過去の延長線から大きく外れる出来事には弱いのです。

急な災害、社会情勢の変化、突発的な価格変動などは、過去のパターンだけでは予測しにくくなります。


## 5. ディープラーニングは「特徴を自分で見つける」

ディープラーニング（深層学習）とは、ニューラルネットワークを何層にも重ねて、複雑な情報を学習する方法です。

従来の機械学習では、人間が「ここを見ればよい」と特徴を指定することがよくありました。
しかし、ディープラーニングでは、AIが大量のデータから重要な特徴を自分で見つけられるようになりました。

これによって、画像認識、音声認識、自然言語処理などの精度が大きく向上しました。

一方で、ディープラーニングには次のような課題もあります。

- 大量のデータが必要
- 高性能な計算資源が必要
- なぜその答えになったのか説明しにくい

とても強力な技術ですが、万能というより「大量のデータと計算力を使って、複雑な特徴をつかむ技術」と見ると理解しやすくなります。


## 6. 画像を扱う代表的なモデル

生成AIを理解するうえでは、画像処理や画像生成で使われてきた代表的なモデルも押さえておきたいところです。
ここでは、CNN、VAE、GANを整理します。


## 7. CNNは画像を「小さな部分」から理解する

CNN（畳み込みニューラルネットワーク）は、画像認識に特化したディープラーニングの代表的なモデルです。

画像をそのまま全部まとめて処理しようとすると、ピクセル数が膨大で計算が大変になります。
そこでCNNは、画像を小さな部分に分けて特徴を抽出します。

たとえば顔写真なら、最初に「線」「角」「色の変化」のような単純な特徴を見つけ、次に「目の輪郭」「口のライン」のような特徴をつかみ、最後にそれらを統合して画像を認識します。

| ステップ | 処理 | 内容 |
| --- | --- | --- |
| 1 | 畳み込み | 画像を小さな部分に分け、線・角・色の変化などを検出する |
| 2 | プーリング | 重要な特徴を残しながら、データ量を減らす |
| 3 | 全結合層 | 分割された特徴を統合し、画像を認識する |

CNNの強みは、画像の部分的な特徴を効率よく捉えられることです。
一方で、大量のデータと高性能な計算資源が必要で、画像にノイズやぼやけが入ると誤認識することもあります。


## 8. VAEはデータを「圧縮して復元する」

VAE（変分自己符号化器）は、データを一度圧縮してから復元するしくみを持つ生成モデルです。

VAEには、大きく分けて「エンコーダ」と「デコーダ」があります。

| 部分 | 役割 |
| --- | --- |
| エンコーダ | 入力データを、重要な特徴を持つ「潜在ベクトル」に圧縮する |
| デコーダ | 潜在ベクトルをもとに、元のデータに近いものを再現する |

たとえるなら、エンコーダは「要点をまとめる係」、デコーダは「要点から元の形に戻す係」です。

VAEは、データの特徴学習、次元削減、データ生成、異常検知などに使われます。
ノイズが混ざったデータから元のデータを再現するような場面にも向いています。


## 9. GANは「作るAI」と「見破るAI」を競わせる

GAN（敵対的生成ネットワーク）は、2014年にイアン・グッドフェローによって提唱された生成モデルです。

GANの特徴は、2つのAIを競争させることです。

| 役割 | 内容 |
| --- | --- |
| 生成器（Generator） | ランダムな数値から、本物そっくりのデータを作ろうとする |
| 識別器（Discriminator） | そのデータが本物か偽物かを見分けようとする |

生成器は、識別器をだまそうとします。
識別器は、生成器が作った偽物を見破ろうとします。

この競争を繰り返すことで、生成器はどんどん本物に近いデータを作れるようになります。

GANは、特に画像や動画の生成で力を発揮してきました。
少ないデータからでもリアルで多様な画像を作れる一方、学習が不安定になりやすいことや、悪用リスクが大きいことには注意が必要です。


## 10. RNNは「過去の情報」を覚えながら処理する

RNN（リカレントニューラルネットワーク）は、過去の情報を記憶しながら次の出力に活かすニューラルネットワークです。

通常のニューラルネットワークは、入力から出力まで一方通行です。
しかしRNNには、ネットワークの中に「戻り道」のような構造があり、前に処理した情報を次の処理に利用できます。

そのため、文章や音声、時系列データのように「順番」が大事なデータに向いていました。

ただし、RNNには弱点があります。
文章が長くなると、昔の情報を忘れてしまう「勾配消失」や、学習の数値が大きくなりすぎる「勾配爆発」が起こりやすいのです。

つまり、短いデータには向いていても、長い文章や長時間データの処理は苦手でした。


## 11. LSTMは「覚える情報」と「忘れる情報」を分ける

LSTM（ロング・ショートターム・メモリ）は、RNNの弱点を補うために生まれたしくみです。

LSTMは、情報を次のように分けて処理します。

- 長く覚えておくべき情報
- 忘れてもよい情報

このしくみによって、長い文章や長時間のデータを扱いやすくなりました。
従来のRNNが苦手だった長い時系列データにも対応しやすくなったのです。

ただし、LSTMにも課題はあります。
基本的には順番に処理するしくみなので、並列処理には向きません。
長文や大規模データを扱うと、学習に時間がかかりやすくなります。


## 12. Transformerが生成AIを大きく前進させた

生成AIを理解するうえで、とても重要なのがTransformerです。

Transformerは、2017年にGoogleの研究者によって提案されたAIモデルです。
特徴は、「自己注意機構（Attention Mechanism）」というしくみを使うことです。

従来のRNNやLSTMは、文章を順番に処理する必要がありました。
そのため、長い文章を扱うと時間がかかり、大規模な学習には向きにくい面がありました。

Transformerは、複数の単語を同時に処理できます。
これにより、学習速度が大きく向上し、大量のテキストを扱いやすくなりました。

この変化が、現在の大規模言語モデルや生成AIの発展につながっています。


## 13. Attentionは「どの言葉に注目するか」を決めるしくみ

Transformerの中心にあるのが、Attentionです。
Attentionは、文章の中でどの単語が重要かを見つけ、その重要度に応じて重みをつけるしくみです。

たとえば、「この花はチューリップです」という文があるとします。
このときAIは、「この」「花」「は」「チューリップ」「です」といった単語の関係を見ながら、どの単語に注目すれば意味を理解しやすいかを判断します。

| 単語 | この | 花 | は | チューリップ | です |
| --- | --- | --- | --- | --- | --- |
| Attentionスコア | 0.06 | 0.6 | 0.03 | 0.3 | 0.01 |

この例では、「花」と「チューリップ」が特に重要だと判断されています。

Attentionによって、AIは文章全体の中で単語同士の関係を捉えやすくなりました。
これが、自然な文章理解や文章生成の土台になっています。


## 14. 位置エンコーディングで「語順」も理解する

文章では、単語の意味だけでなく、並び順も重要です。

たとえば、「私はコーヒーを飲む」と「コーヒーは私を飲む」では、使われている単語が似ていても意味はまったく違います。

そこでTransformerでは、「位置エンコーディング」という技術を使います。
これは、単語が文のどこにあるのかという情報をAIに渡すしくみです。

Attentionで単語同士の関係を見ながら、位置エンコーディングで語順の情報も補う。
この組み合わせによって、Transformerは自然な文章の意味を処理できるようになります。


## 15. エンコーダとデコーダの役割

Transformerは、エンコーダとデコーダという2つの部分で説明されることがあります。

| 部分 | 役割 |
| --- | --- |
| エンコーダ | 入力された文章やデータの要点を理解する |
| デコーダ | 理解した内容をもとに、新しい出力を作る |

たとえば質問応答で考えると、エンコーダは長い質問の要点を読み取り、デコーダはそれに対する答えを生成します。

もちろん実際のAIモデルはもっと複雑ですが、「理解する部分」と「作る部分」があると考えると、全体像をつかみやすくなります。


## 16. GPTは文章を生成するモデルとして発展した

Transformer以降、さまざまな派生モデルが登場しました。
代表的なものがGPTとBERTです。

GPT（Generative Pretrained Transformer）は、2018年にOpenAIが発表したモデルです。
大量のテキストを事前に学習し、その学習結果をもとに新しい文章を生成します。

GPTの大きな特徴は、自然で一貫性のある文章を作る力です。
その後も改良が進み、ChatGPTのような対話型AIへと発展していきました。

生成AIの文章生成を理解するうえで、GPTは非常に重要なモデルです。


## 17. BERTは文脈を深く理解するモデル

BERT（Bidirectional Encoder Representations from Transformers）は、2018年にGoogleが開発したモデルです。

BERTの特徴は、「双方向性」です。
文中の単語を理解するときに、その前の言葉だけでなく、後ろの言葉も同時に見ます。

たとえば、「ご飯をはしで食べる」という文では、「ご飯」と「食べる」という前後の言葉から、「はし」は「橋」ではなく「お箸」だと判断できます。

BERTは、文章の意味を深く理解することに強いモデルです。


## 18. BERTの学習方法 - MLMとNSP

BERTでは、代表的な学習方法としてMLMとNSPが使われます。

### MLM（Masked Language Model）

MLMは、文章の一部を隠し、前後の文脈から隠された単語を予測する学習方法です。

たとえば、「朝ごはんに○○を食べた。」という文があるとします。
この場合、「朝ごはん」「食べた」という前後の言葉から、「パン」「ごはん」「卵」などが入りそうだと予測します。

### NSP（Next Sentence Prediction）

NSPは、2つの文が自然につながるかどうかを予測する学習方法です。

たとえば、「今日はとても暑い」のあとに「アイスクリームを買った」が続くのは自然です。
一方で、「今日はとても暑い」のあとに「おもちゃを買いに行った」が続く場合、文のつながりはやや弱くなります。

このように、BERTは単語だけでなく、文章全体の流れも学習します。


## 19. RoBERTaとALBERTはBERTの改良版

BERTのあとには、さらに改良されたモデルも登場しました。

RoBERTaは、2019年にFacebook AI（現Meta AI）が発表したモデルです。
BERTより多くのデータを使い、長く学習することで、言語理解能力をさらに高めました。

ALBERTは、2019年にGoogleが開発したモデルです。
BERTを軽量化し、少ない計算リソースでも使いやすくすることを目指しました。

| モデル | 特徴 |
| --- | --- |
| GPT | 文章生成に強い |
| BERT | 文脈理解に強い |
| RoBERTa | BERTをより強化したモデル |
| ALBERT | BERTを軽量化したモデル |

ここでいう「計算リソース」とは、パソコンやサーバーの性能、メモリ、電力、バッテリーなどのことです。
AIを実際に動かすには、モデルの性能だけでなく、どれくらい軽く動かせるかも重要になります。


## まとめ

生成AIは、ただ文章や画像を作っているだけの技術ではありません。
その背景には、データの特徴を学ぶしくみ、過去から次を予測するしくみ、画像を理解するしくみ、文章の文脈を捉えるしくみなど、さまざまな技術があります。

流れを大きく見ると、次のようになります。

| 技術 | 役割 |
| --- | --- |
| ボルツマンマシン | 複雑なデータを確率的に学習する |
| 制約付きボルツマンマシン | 情報の流れを整理し、学習しやすくする |
| 自己回帰モデル | 過去のデータから次を予測する |
| ディープラーニング | データの重要な特徴を自動で見つける |
| CNN | 画像を小さな部分から認識する |
| VAE | データを圧縮し、復元・生成する |
| GAN | 生成器と識別器を競わせて本物に近づける |
| RNN・LSTM | 時系列データや文章の流れを扱う |
| Transformer | 複数の単語を同時に処理し、文脈を理解する |
| GPT・BERT系 | 文章生成や文脈理解を大きく発展させる |

生成AIは、こうした技術が積み重なった結果として生まれました。
だからこそ、ChatGPTのような対話AIも、画像生成AIも、単なる便利ツールではなく、長いAI研究の上に成り立っている技術だといえます。
