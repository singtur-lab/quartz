# Obsidian + Quartz + GitHub + Cloudflare という環境
2026/07/07

## この環境が最強な理由
恐らく今後、「**Obsidian + Quartz + GitHub + Cloudflare**」というサイト構築が、個人のサイトとしては最適解になるであろうと私は考えています。

1. 全てが無料である。
2. 半永久に残る。
3. 容量がほぼ無制限である。
4. PC・スマホ内で書いたObsidianのメモがそのままHPになってしまう。
5. ObsidianのプラグインのAIに相談しながら、文章が書ける。
6. 文章を書いている最中は基本、オフラインの環境でも一切問題がない。
7. アフィリエイト、バナーが制限無しにつけ放題である。

（今後、気がついた事があったら日付をつけて追記していきます。）

## この環境構築と発信が重要な理由
今後、個人の日記、記録やメモは、個人がAIと”一生”付き合っていく上で重要な「資産」となります。

2026年7月現在のネット界隈では、ObsidianやNotionでの「第2の脳」の構築が大ブームですが、それにはまだ重要な要素が足りてません。

そのヒントを書きます。

1. Obsidian、Notionでの「第2の脳」（これは第1の要素）
2. ObsidianからCloudflareへの永久保存
3. 1行日記によるタイムスタンプ付き行動記録

上記の情報を長期保存・追加することによって、個人の思考や行動はAIに完全に把握してもらえるようになります。これの優位性はまだ、理解が及ばないかもしれませんが、この一言で伝わるとありがたいです。

**「1〜3のデータを数年分、NotebookLMに取り込ませたらどうなるか？」**

勘の良い人なら気がつくかもしれません。
AIがあなたのクローンになります。

これは、あなたの代わりにAIがXに投稿を呟いたり、noteの記事を書いてくれたり、あるいは、画像や動画も将来的には勝手に作ってくれるようになります。

これが、恐らく、10年以内には技術的に実現できます。
その時必要になるのが、あなたの思考や行動規範の情報なのです。

これが、私が「**Obsidian + Quartz + GitHub + Cloudflare**」を強く推奨する理由です。
クライアントPCの中でObsidian、インターネット上でCloudflareを。
これによって、将来のAIのモデルは、あなたの情報をインターネット上でクロールし、あなたが名前を名乗るだけで、あなたを理解してくれます。
これによって、プロンプトもスキルも、何も必要なくなります。

既にAIのモデルの中に、あなたの情報が内在しているからです。
そして、あなたの最新の情報や近況をObsidianで読み込ませるだけです。

これが私の未来予想図です。
そして、半永久的に残るCloudflareはインターネット上のあなたの墓石になります。

運良く偶然、このサイトに辿り着きこの意義を感じ取れた方は、私まで気軽に連絡をしてください。この環境の構築のアドバイスをお伝えします。

ちなみにですが、あえて、補足しますと。
「**Obsidian + Quartz + GitHub + Cloudflare**」＋「**Antigravity＋Claude code + codeX**」です。ただ、AIエージェントはなんでもいいし、そもそも、サイトに書く文章はAIに書かせたら意味がないので、デザインや文章の誤字脱字やリンク生成等に使ってください。
