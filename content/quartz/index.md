# Obsidian + quartz + GitHub + Cloudflare という最適解
2026/07/07

## この環境が最強な理由
恐らく今後、「**Obsidian + Quartz + GitHub + Cloudflare**」というサイト構築が、個人のサイトとしては最適解になるであろうと私は考えています。

1. 全てが無料である。
2. 半永久に残る。（著者が死んでも残る）
3. 容量がほぼ無制限である。
4. WordPressと違い、メンテナンスフリー。
5. PC・スマホ内で書いたObsidianのメモがそのままHPになってしまう。
6. ObsidianのプラグインのAIに相談しながら、文章が書ける。
7. 文章を書いている最中は基本、オフラインの環境でも一切問題がない。
8. アフィリエイト、バナーが制限無しにつけ放題である。

（今後、さらに有利な点があったら日付をつけて追記していきます。）

## この環境構築と発信が重要な理由
今後、個人の日記、記録やメモは、個人がAIと”一生”付き合っていく上で重要な「資産」となります。

2026年7月現在のネット界隈では、ObsidianやNotionでの「第2の脳」の構築が大ブームですが、それにはまだ重要な要素が足りてません。

1. Obsidian、Notionでの「第2の脳」
2. ObsidianからCloudflare・インターネットへの永久保存
3. 1行日記によるタイムスタンプ付き個人の行動記録

上記の2,3の情報を長期保存することによって、個人の思考や行動はAIに完全に把握してもらえるようになります。これの優位性はまだ理解が及ばないかもしれませんが、以下の一言で伝わるとありがたいです。

**「1〜3のデータを数年分、NotebookLMに取り込ませたらAIはどうなってしまうか？」**

勘の良い人なら気がつくかもしれません。**AIはあなたのクローンになります。**

将来的に、あなたの代わりにAIがXに投稿を呟いたり、noteの記事を書いてくれたり、あるいは、画像や動画、ツールも勝手に作ってくれるようになります。

これが、恐らく、10年以内には技術的にも環境的にも実現します。
その時に必要となるのが、**あなたの思考や行動規範の情報**なのです。

これが、私が「**Obsidian + Quartz + GitHub + Cloudflare**」を強く推奨する理由です。
クライアントPCの中でObsidian、インターネット上でCloudflareで公開。
これによって、将来のAIのモデルは、あなたの情報をインターネット上でクロールし、あなたが自分の名前を名乗るだけで、あなたを理解して動いてくれます。
これによって、プロンプトもスキルも、何もかも一切必要なくなります。

その理由は、最新のAIモデルの中に、あなたの結晶化した情報が内在しているからです。

これが私の未来予想図です。
そして、半永久的に残るCloudflareはインターネット上のあなたの結晶体そのものになります。
あなたが”実名”で自分自身を名乗れば、AIはあなた過去の文脈を遡り、解析し、認識して会話してくれます。この状況が数年後には実現できるのです。

運良く偶然、このサイトに辿り着き、この意義や意味を感じ取れた方は、私まで連絡をしてください。この環境構築のアドバイスをお伝えいたします。

ちなみにですが、あえて補足しますと。
実際の私の「**Obsidian + Quartz + GitHub + Cloudflare**」＋「**Antigravity＋Claude code + codeX**」です。ただ、AIエージェントはなんでもいいし、そもそも、サイトに書く文章はAIに書かせたら意味がないので、AIへの依頼はデザインや文章の誤字脱字やリンク生成等に使ってください。

という事で。今日の記録は以上です。
